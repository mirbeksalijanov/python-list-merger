# 🐍 Python List Merger Project

Добро пожаловать в мой учебный репозиторий! Этот проект посвящен изучению работы со структурами данных в Python, а именно — **слиянию списков**.

## 📌 Описание задачи
Слияние списков — одна из самых частых задач при обработке данных. В этом примере я реализовал объединение двух коллекций в одну новую переменную.

### Что изучено в процессе:
*   Создание списков в Python[cite: 2].
*   Использование оператора `+` для конкатенации (склеивания) коллекций[cite: 2].
*   Работа с F-строками для красивого вывода данных в консоль.
*   Структурирование кода с помощью функций (`def`) и точки входа (`if __name__ == "__main__":`).

1. Склонируйте репозиторий или просто скачайте файл `list_merge.py`.

3. Запустите скрипт через терминал:
